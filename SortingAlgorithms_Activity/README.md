### &#x09;			**Sorting Algorithms Activity**



***Program Description***



* Kani nga Java program gapakita kung gi unsa pag arrange ang mga number gikan sa pinakagamay hangtod sa pinakadako. Nag gamit ko ug tulo ka sorting algorithm which are ang Bubble Sort, Selection Sort, ug Insertion Sort. Ang kada algorithm naa'y kaugalingong way sa pag arrange o pag han-ay sa mga numero.



***How Each Sorting Algorithm Works***



&#x09;**1. Bubble Sort**



* Ang Bubble Sort mag compare sa duha ka tapad nga number. Kung ang una nga number mas dako kaysa sa ikaduha, ilang ilisan ang ilang pwesto. Balik-balikon dayon ni nga process hangtod ma arrange ang tanan nga numbers. Sa kada round, ang pinakadakong number mobalhin sa last.



&#x09;**2. Selection Sort**



* Ang Selection Sort mangita sa pinakagamay nga number sa wala pa na arrange nga part sa array. If ma kita na, ibalhin dayon sa una nga pwesto. Balik-balikon gyapon ni nga process  hangtod ma plastar na sa saktong pwesto ang kada number.



&#x09;**3. Insertion Sort**



* Ang Insertion Sort mag start sya sa ikaduhang number ug e compare sa mga number nga naa sa left which is left number sa ikaduha nga number, like if ang numbers kay 2 and 3 e compare dayon ang 2 (2nd nga number) sa 3 (left number). Kung naa'y mas dako nga number, ibalhin dayon sa sunod nga pwesto aron mahatagan og room ang number nga isulod. e continue ra day'n ang process hangtod ma arrange ang tibuok array.





***Differences Between the Three Sorting Algorithms***



* Ang **Bubble Sort** mag compare sa ga **tapad nga number** ug magbaylo sa ilang pwesto. Ang **Selection Sort** mangita una sa pinakagamay nga numero. While ang **Insertion Sort** magkuha ug isa ka number ug ibutang sa sakto nga pwesto bisan pag ang uban nga number sa array kay na arrange na.





***Reflection Questions***



&#x09;**1. How does each sorting algorithm arrange numbers? What makes their processes different?**



* Ang tulo ka algorithms parehas ug purpose which is nga ma arrange ang mga number gikan sa pinakagamay hangtod sa pinakadako. Ang Bubble Sort mag compare sa mag tapad nga number, ang Selection Sort mangita sa pinakagamay nga number, ug ang Insertion Sort mag insert sa numero sa iyang sakto nga pwesto. So the way sila mag arrange isa lahi-lahi but same purpose which ang pag arrange sa mga numbers.



&#x09;**2. Among the three sorting algorithms, which one do you think is the easiest to understand and implement? Why?**



* Para nako, ang Insertion Sort ang pinakasayon sabton ug buhaton kay dali ra ang pag process. Ngano? Magkuha lang og usa ka number ta's e compare dayon sa mga number sa wala, ug ibutang sa saktong pwesto. Mas sayon nako sya masabtan kay isa ra ka number ang akong e compare and mas less pod nga time ang ma gamit.



&#x09;**3. If the numbers are already sorted, which algorithm do you think would perform better? Explain your answer based on how the algorithms work.**



* Para nako, ang Insertion Sort ang mas nice kung ang mga number na arrange na sa sakto nga plastar. Dili na sya needed nga ibalhin pa ang mga numbers kay naa na sila sa ilang sakto nga pwesto. So, mas gamay ra ang buhaton kung sorted na ang array.



&#x09;**4. What will happen if you add more numbers to your array? How might this affect the performance of each sorting algorithm?**



* Kung modaghan man galing ang mga numbers sa array, mas daghan pod ang e compare ug e plastar sa kada algorithm. Ta's mas dugay mahuman ang sorting process, labi na kung daghan ang mga numbers nga wala pa na arrange. So, importante nga pilion ang sort nga suitable sa daghan nga numbers.
